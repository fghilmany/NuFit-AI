# NuFit AI

AI-powered gym companion app for beginners — Kotlin Multiplatform (Android + iOS) with shared Compose Multiplatform UI.

**Local-first**: every core feature works fully offline (SQLDelight is the source of truth). Login is optional (Google-only); the cloud is used only for auth, AI features, and sync. Three tiers: **Local** (template-matrix plans), **Logged In** (rule-based engine + Chat AI basic), **Subscribe** (AI custom plans).

Full product analysis lives in `.claude/rules/US/` (1 feature = 1 user story file, `00-overview.md` is the index).

## Project Structure

```
androidApp/          Android entry point (MainActivity)
iosApp/              iOS entry point (Xcode project, SwiftUI shell)
shared/              All shared code (UI + logic), Clean Architecture:
  src/commonMain/kotlin/com/fghilmany/nufitai/
    core/            error (AppResult/Failure), util
    domain/<feature>/  entities + repository interfaces (pure Kotlin)
    usecase/<feature>/ one class per operation, operator fun invoke()
    data/<feature>/    datasources (SQLDelight) + repository impls
    presentation/<feature>/ ViewModel (MVI: sealed State/Event) + screens + components
    navigation/      Compose Navigation, type-safe routes
    di/              Koin modules (manual DSL — see docs/decisions.md ADR-001)
    db/              DatabaseDriverFactory (expect/actual)
  src/androidMain/   Android actuals (SQLDelight driver)
  src/iosMain/       iOS actuals (native driver)
  src/commonTest/    shared unit tests (kotlin.test, Turbine, hand-written fakes)
  src/androidHostTest/ JVM tests incl. mandatory DiVerificationTest (checkModules())
docs/
  decisions.md       ADRs — approved deviations from .claude/rules
  techspec/          feature techspecs (generated by /techspec)
```

Dependency rule: `presentation → usecase → domain ← data`. Errors never thrown across layers — always `AppResult<T>` / `Failure`.

## Tech Stack (locked — see `.claude/rules/tech-stack.md`)

Compose Multiplatform · ViewModel + StateFlow (MVI) · Koin (manual DSL, ADR-001) · SQLDelight · Compose Navigation (type-safe routes) · kotlinx-datetime · kotlinx.serialization · every dependency via `gradle/libs.versions.toml`.

## Building & Testing (run by the dev)

- Android app: `./gradlew :androidApp:assembleDebug`
- iOS app: open `iosApp/` in Xcode and run
- Shared tests (JVM, incl. DI check): `./gradlew :shared:testAndroidHostTest`
- iOS simulator tests: `./gradlew :shared:iosSimulatorArm64Test`
